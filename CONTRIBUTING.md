# Contribuir

Gracias por querer mejorar este repositorio. Se aceptan correcciones, mejoras y propuestas de la comunidad.

## Qué puedes aportar

- Corregir errores técnicos, de redacción o enlaces rotos.
- Mejorar una explicación o agregar un ejemplo.
- Proponer un tema nuevo o un módulo que falte.
- Completar una lección marcada como pendiente.

## Antes de empezar

- Revisa los issues y pull requests abiertos para no duplicar trabajo.
- Para cambios grandes (lecciones nuevas, reestructuración), abre un issue primero y espera respuesta.

## Flujo de trabajo

La única rama de larga vida es `main`. Todo cambio entra por pull request.

1. Haz un fork del repositorio, o crea una rama si tienes acceso de escritura.
2. Crea una rama corta desde `main` con uno de estos prefijos:
   - `feat/<tema>`: lección, ejercicio o módulo nuevo.
   - `fix/<tema>`: corrección de errores.
   - `docs/<tema>`: README, redacción o documentación.
   - `chore/<tema>`: estructura, configuración o mantenimiento.
3. Escribe commits con [Conventional Commits](https://www.conventionalcommits.org/es/v1.0.0/) en español, por ejemplo `docs(funciones): agrega ejemplo de closures`.
4. Abre un pull request hacia `main` y completa la plantilla. Un pull request, un propósito.
5. Tras la revisión se fusiona con squash y la rama se elimina.

## Criterios de contenido

- Todo en español, directo y sin relleno.
- Cada lección sigue esta estructura: objetivo, idea clave, ejemplo mínimo, error común, ejercicio y, si aplica, fuentes.
- Los ejemplos de código deben ejecutarse y estar probados.
- No se copia material de cursos, libros o videos. Se explica con palabras propias y se cita la fuente.
- Una lección con contenido útil vale más que diez archivos vacíos: no se agregan archivos sin contenido.

## Nombres de archivos y carpetas

- Minúsculas, sin tildes ni espacios, separados con guiones.
- Prefijo numérico de dos dígitos para el orden: `01-variables.md`.

## Licencia de los aportes

Al contribuir aceptas que el contenido escrito se publique bajo CC BY 4.0 ([`LICENSE-CONTENT.md`](LICENSE-CONTENT.md)) y el código bajo MIT ([`LICENSE`](LICENSE)).

## Trato entre personas

Se critica el contenido, no a la persona. Las discusiones se mantienen respetuosas y enfocadas en mejorar el material.
